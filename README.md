# Nautilus-Solder-Project
Solder Submission for Hack Club!
I made this with the help of 2 friends. ^_^

Parts List:
- 2 Resistors
- 1 photoresistor
- 1 mini motor disc
- 1 potentiometer
- 2 6mm push buttons
- 2 5mm LEDs
- 1 bCR2032 battery cell
